# Camera Topic Viewer - pip 依赖
# 适用环境: Ubuntu 22.04 + Python 3.10（系统 Python，非 conda）
#
# ⚠️  重要: ROS2 Humble 的 rclpy/cv_bridge 仅支持 Python 3.10。
#     不要在 conda Python 3.11/3.12 环境中运行本工具。
#
# 安装步骤:
#   1. 安装 ROS2 Humble 系统包:
#      sudo apt update
#      sudo apt install -y \
#          ros-humble-rclpy \
#          ros-humble-cv-bridge \
#          ros-humble-sensor-msgs \
#          python3-pip
#
#   2. 用 Python 3.10 安装 pip 依赖（不要用 conda 的 pip）:
#      python3.10 -m pip install --user -r requirements.txt
#
#   3. 运行:
#      bash run_in_docker.sh     # ROS 在 Docker 内（推荐）
#      bash run.sh               # ROS 在宿主机
